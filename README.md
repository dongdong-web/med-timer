# 吃药计时

一个极简的吃药记录页：**一个按钮 + 一个计时器**。点一下 = 吃下一种药，自动记时间、自动算间隔；最后点「结束这一轮」看总计。

打开即用：<https://dongdong-web.github.io/med-timer/>

## 怎么用

- **点大圆按钮**：记下一种药，计时从 00:00 重新开始，底部显示「已吃 N 种 · 总用时」
- **进度环**：按钮外圈那道弧线随着等待慢慢绕满，一眼看出还剩多久
- **到间隔了**（默认 15 分钟，可点「间隔」在 10 / 15 / 20 分钟之间切换）：按钮变绿、轻振一下、响一声柔和提示音
- **还没到间隔就点**：先弹一句确认，确定后照记，记录页里这一段会标红 ⚠
- **点「结束这一轮」**：出总计 —— 共几种、历时多久、每种药的具体时间和间隔
- **「撤销」**：点错了回退一种（1.5 秒内连点两下会被忽略，防手滑）
- **右上角喇叭**：开关提示音
- 药数不固定，想吃几种就点几次

进度存在浏览器本地（localStorage），刷新、锁屏、关掉再打开都不丢；深色模式自动跟随系统。

## 声音说明

提示音用 WebAudio 实时合成，没有音频文件、不额外加载资源。第一次点按钮时解锁音频（浏览器要求用户手势），之后到点就会响。用 iPhone 静音键静音时系统会拦掉声音，那时还有振动和变绿的按钮。

## 省电用法：iPad 别常亮，提醒交给系统

屏幕常亮是 iPad 的耗电大头（背光就占 3～5W），而且锁屏后 Safari 会被挂起，网页里的声音和定时器都叫不醒你。所以：

**页面只负责记录，提醒交给 iPad 自己。**

页面本身是「锁屏友好」的：全程按时间戳算，锁屏 40 分钟再打开，显示的就是 `40:00` + 变绿，不会算错、不会漏记。所以 iPad 可以在「设置 → 显示与亮度 → 自动锁定」里设成 1 分钟。

提醒有两种低成本做法（都不耗电）：

### 1. 一句话（零配置）

每点完一次，对 iPad 说：

> 嘿 Siri，设置 15 分钟计时器

计时器走系统，锁屏、切到别的 App 都照样响，而且倒计时声音一般不受静音键影响（网页里的声音会被掐）。15 分钟要跟页面上的「间隔」一致。

想留痕就用提醒事项：

> 嘿 Siri，15 分钟后提醒我吃药

### 2. 一键（推荐，5 分钟搭一次）

做一个快捷指令，点一次 = 打开这个页面 + 自动开 15 分钟计时器，放在桌面上：

1. 打开「快捷指令」App，右上角 **＋** 新建
2. 添加操作：搜索 **URL**，选「打开 URL」，填 `https://dongdong-web.github.io/med-timer/`
3. 再加一个操作：搜索 **计时**，选「开始计时」（时钟分类），时长填 **15 分钟**
   - 系统比较老、找不到「开始计时」的话：改用「提醒事项 → 添加新提醒事项」，标题写「吃下一种药」，展开详情勾选「在指定时间提醒我」，日期选 **当前日期 +15 分钟**
4. 顶部名称改成「吃药」，选个图标颜色 → 完成
5. 回到桌面：主屏幕小组件里放一个「快捷指令」组件，或者长按指令 → 分享 → 添加到主屏幕

之后每次：点桌面「吃药」→ 页面打开 + 计时器开始跑 → 点页面大圆按钮记录 → 计时器到点响（锁屏也响）→ 回来点第二次。

> 注意：改页面上的间隔（10/15/20 分钟）时，快捷指令里的时长也要一起改。

### 3. 常见坑：别把「开始计时」放进「重复」里

iPadOS 17 起，「时钟」支持**多个计时器同时跑**（老系统才是一个顶替一个），而「开始计时」是从**运行那一刻**开始倒数。所以如果在「重复 5 次」的循环里放「开始计时 15 分钟」，会得到 **5 个同时倒数的计时器**，15 分钟后一起响——这就是"一下子启动 5 个倒计时"的原因。

两条路，按需要选：

**A. 一次只开一个（推荐）**

快捷指令里**不要循环，只放一个**「开始计时 15 分钟」。每次吃药点一次桌面「吃药」图标：

- 页面记录 + 这一个计时器，永远是一对
- 吃几种、吃得早或晚都不乱，下一次永远从"刚刚"开始算
- 页面上的「间隔」改了，这里也跟着改

**B. 想一次排完整轮：用「提醒事项」，别用计时器**

计时器是**相对时间**（从现在起 15 分钟），提醒事项可以设**绝对时间**。所以循环里放"提醒"是对的，放"计时器"是错的：

1. 「获取当前日期」→ 起个变量名，比如 `开始时间`
2. 「重复」5 次（次数也可以设成变量，按今天几种药）
3. 循环里依次放：
   - 「计算」：`15 × 重复索引`（"重复索引"是循环里的魔法变量）→ 存成 `偏移`
   - 「调整日期」：`开始时间` 加上 `偏移` 分钟 → 存成 `提醒时间`
   - 「添加新提醒事项」：标题「吃下一种药」；展开详情 → 打开「在指定时间提醒我」→ 日期填 `提醒时间`
4. 每条提醒的时间是 15 / 30 / 45 … 分钟，各自在自己的时刻响，不会一起启动

代价是：**如果某次吃晚了，后面的提醒不会自动顺延**——所以药必须吃得比较准时，才适合用 B。时间不固定的，用 A。

**清了已经开出去的一堆计时器**：打开「时钟」App →「计时器」，把多余的逐个左滑删掉；或者对 Siri 说「停止所有计时器」。

仓库根目录的 `index.html` 就是全部代码（单文件、无依赖），GitHub Pages 直接发布根目录即可。
